# 上市櫃公司於美國子公司概況

整理上市櫃公司在美國的子公司資料，可依母公司、州別、半導體產業供應鏈篩選，並匯出 Excel 或 PDF。

- 資料來源：各公司公開的「114 年關係企業合併營業報告書」與「115 年第 2 季合併財報」。
- 產業鏈分類：證交所／櫃買中心「產業價值鏈資訊平台」。
- 營收與損益單位為新台幣仟元；實收資本額依報告書載明的幣別。
- 資料為人工與程式整理，僅供參考，請以原始報告書為準。
